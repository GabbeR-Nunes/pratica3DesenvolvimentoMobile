# Biblioteca Pessoal — projeto Android Studio

Projeto Kotlin com Jetpack Compose, Material 3 e Navigation Compose.

## Abrir
1. Extraia o ZIP.
2. No Android Studio, use **File > Open** e selecione esta pasta `BibliotecaPessoal_ProjetoCorrigido`.
3. Aguarde a sincronização do Gradle.
4. Execute a configuração `app` em um emulador ou dispositivo Android.

## Ambiente
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Kotlin 2.0.21
- JDK 17
- Android SDK 35

## Observações
- As quatro telas são Lista, Cadastro, Detalhes e Sobre/Ajuda.
- A lista compartilhada é mantida em um ViewModel.
- Os registros ficam em memória enquanto o aplicativo está aberto.
- Edite os autores em `app/src/main/java/com/example/bibliotecapessoal/ui/SobreTela.kt`.
